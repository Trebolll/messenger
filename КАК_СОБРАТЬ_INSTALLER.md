# Как собрать установщик Messenger для Windows

## Что включено

В папке проекта уже есть все нужные файлы:

| Файл | Назначение |
|------|-----------|
| `start.bat` | Запуск приложения |
| `stop.bat` | Остановка приложения |
| `update.bat` | Пересборка и обновление |
| `install_prereqs.bat` | Автоматическая установка Docker |
| `installer/setup.iss` | Скрипт для Inno Setup |

---

## Шаг 1 — Установить Inno Setup

Скачай бесплатный инструмент:
👉 https://jrsoftware.org/isdl.php

Установи как обычную программу.

---

## Шаг 2 — Собрать .exe установщик

1. Открой файл `installer/setup.iss` в **Inno Setup Compiler**
2. Нажми **Build → Compile** (или F9)
3. Готовый файл появится в папке `installer/output/MessengerSetup.exe`

---

## Что делает установщик

При запуске `MessengerSetup.exe` на компьютере пользователя:

1. ✅ Копирует все файлы проекта в `C:\Program Files\Messenger`
2. ✅ Автоматически проверяет наличие Docker Desktop
3. ✅ Если Docker не установлен — скачивает и устанавливает его
4. ✅ Создаёт ярлыки в меню Пуск и на рабочем столе
5. ✅ Запускает `docker compose up` и открывает браузер на `http://localhost`

---

## Требования к компьютеру пользователя

- Windows 10 / 11 (64-bit)
- Минимум 4 GB RAM (рекомендуется 8 GB)
- Интернет для первого запуска (скачивание Docker-образов)
- Права администратора

---

## Запуск / остановка после установки

| Действие | Способ |
|----------|--------|
| Запустить | Ярлык на рабочем столе или `start.bat` |
| Остановить | Меню Пуск → Messenger → Остановить |
| Открыть приложение | http://localhost |
| MinIO консоль | http://localhost:9001 |

---

## Удаление

Стандартное удаление через «Программы и компоненты» Windows.
Docker Desktop и данные БД при этом **не удаляются** (для безопасности).
